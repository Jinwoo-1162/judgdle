# JUDGDLE — The Daily Conviction Matching Game

A daily legal puzzle game inspired by Wordle and judicial court dockets, featuring an old-money courtroom aesthetic.

## Quick Start (Local Setup)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Vite Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 3. Initialize Git Repository
```bash
git init
git add .
git commit -m "feat: initial commit of Judgdle workspace"
```

## Working with Antigravity CLI

## Project Structure
- `src/App.jsx`: Complete core game state, 4-pillar judicial sentencing builder, 5-stage case exhibits, and public docket cases.
- `src/index.css`: Tailwind directives and font configurations.
- `index.html`: Web font links for Playfair Display & Plus Jakarta Sans.
